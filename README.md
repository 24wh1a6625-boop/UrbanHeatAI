# UrbanHeatAI

## AI-Powered Urban Heat Mitigation Using Satellite Data

## Problem

Urban areas are experiencing increasing temperatures due to rapid urbanization, loss of vegetation, and heat-absorbing surfaces. City planners need a data-driven system to identify heat hotspots and understand their causes.

## Solution

UrbanHeatAI uses satellite imagery and Artificial Intelligence to:

- Map urban heat hotspots
- Analyze vegetation impact
- Identify reasons behind extreme heat
- Recommend suitable mitigation strategies

## Current Implementation

- Land Surface Temperature mapping using Landsat 9
- Vegetation analysis using Sentinel-2 NDVI
- Satellite data processing using Google Earth Engine

## Technology Stack

- Google Earth Engine
- Landsat 8/9
- Sentinel-2
- Python
- Machine Learning
- Streamlit
